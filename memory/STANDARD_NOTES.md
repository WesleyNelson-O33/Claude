# Standard EH pay-line notes (use the same wording every pay run)

Replace the dates with the current fortnight. Pay run FN = fortnight ending (the Friday).

## Part-time admin staff on contracted hours, no timesheets
Who: anyone on the Staff tab with Employment Type = Part-time, contracted hours in column Q,
and column U (Timesheets & roster required) = No.
One Permanent Ordinary Hours line for the contracted hours, with this in Notes:

```
DD/MM/YYYY to DD/MM/YYYY - Contracted part-time hours, 40 h per fortnight, no timesheets (admin). Pay run FN ending DD/MM/YYYY.
```

Example (pay run 9): `17/10/2026 to 30/10/2026 - Contracted part-time hours, 40 h per fortnight, no timesheets (admin). Pay run FN ending 30/10/2026.`

## Bonus leave accrual
```
Bonus Leave accrual, 1 day (8 h), pay run FN ending DD/MM/YYYY, per <approver>
```
Part-timers: a day is their contracted hours per day, not 8 (e.g. 56 h fortnight = 5.6 h).

## Per diem
```
1 x Day $125.00 - Cost centre: <cost centre number> - <client> - <job> - DD.MM.YY [PRD]
```

## Overtime lines: hours vs multiplier (always explain this to Graham)
On an EH overtime line the Hours box is the hours worked, not the rate multiplier. A 1 hour shift
at x1.5 is entered as Hours = 1 on the "Permanent - Overtime x1.5" category; EH applies the 1.5 through
the rate. Typing 1.5 in Hours overpays and makes the total hours wrong (81.5 instead of 81).
Every time a full-timer has overtime in the approval email to Graham, add one line explaining it, e.g.:

```
<Name>: <N> h ordinary plus <X> h overtime at x1.5 (over 80 h). Total hours <N+X> match the timesheet; the x1.5 is in the rate, not the hours.
```
