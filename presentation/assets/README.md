# Logo files

Put the real CTS logo here and rebuild with `node presentation/build_template.js`:

- `cts-logo.png` for white backgrounds (content slides, light cover)
- `cts-logo-dark.png` for black and navy backgrounds (dark cover, section divider);
  if it is missing, `cts-logo.png` is used on those too

PNG with a transparent background is best. JPG also works. Supply the highest
resolution you have: the file is scaled down to the logo height on each layout.
While no file is here, the layouts show a placeholder "CTS" mark.
